# Knows the basic tactical motifs (fork, pin, skewer)

User reports already knowing fork, pin, and skewer (and likely others) by concept
(2026-06-17). Do NOT spend a lesson teaching what these motifs are.

Caveat to watch: knowing a motif by name is not the same as spotting it instantly under
3+2 blitz time pressure. Recognition *speed* may still be a gap. So if puzzle work comes
up, frame it as timed pattern-recognition reps (Lichess Puzzle Storm / themed speed reps),
not as "here's what a fork is."

Implication: next lessons skip motif instruction. Prioritize basic checkmates (converting
won positions) and applying the scan in real games. Tactics work, if any, is speed-based.
